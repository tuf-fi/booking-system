# Design system

Tokens live in `src/index.css` under `@theme`. Don't add new colors or radii without updating this file.

## Direction

Warm, calm and photo-led, in the spirit of Airbnb and Vrbo: large rounded photos, generous space, one strong action per screen. Friendly rather than corporate. Sentence-case copy, short and plain.

## Color

| Token | Value | Use |
|---|---|---|
| paper | #FAF8F4 | Page background |
| surface | #FFFFFF | Cards, inputs |
| sand | #F1EDE5 | Hover, quiet panels, booked-date stripes |
| ink | #16231D | Text, selected dates, dark buttons |
| muted | #5F6B64 | Secondary text |
| line | #E6E2DA | Borders |
| leaf / leaf-deep / leaf-tint | #2F6B4F / #1F4D38 / #E5EFE9 | Primary action, confirmed, in-range dates |
| sun / sun-tint / sun-ink | #F2B33D / #FBEFD0 / #7A5200 | Waiting states, references, highlights |
| sky-tint / sky-ink | #E3EEF3 / #1F4B62 | Payment instructions, staying now |
| danger / danger-tint | #A8402E / #F7E4DF | Errors, cancel, blocked dates |

Text on tinted backgrounds uses the matching `-ink` or `-deep` token to keep contrast above 4.5:1.

## Type

- One family: Nanum Gothic, in 400, 700 and 800. Headings and prices use 700 to 800 with slightly tight tracking. Body uses 400 and 700.
- The font is bundled through `@fontsource/nanum-gothic` (latin subset), so the demo works offline.

## Shape and depth

- Cards: `rounded-card` (1.25rem), 1px `line` border. Photos in cards use `rounded-3xl`.
- Buttons and chips: fully rounded. Inputs: `rounded-2xl`.
- Shadows: `shadow-soft` for resting cards, `shadow-lift` for hover and floating search.

## Glass

Glassmorphism is a visual design style that mimics frosted glass by combining semi-transparency, background blur, and subtle light borders to create depth. It is the style for anything that floats above content.

| Class | Recipe | Use |
|---|---|---|
| `.glass` | 72% white, 18 px blur, 160% saturation, 1 px white border, inner top highlight, soft shadow | Navbar over the hero, search bar, photo captions, chips on photos |
| `.glass-strong` | 88% white, 24 px blur, same border and highlight | Navbar after scrolling, mobile menu, dialogs, sticky bars, admin header, booking summary |
| `.glass-dark` | 62% ink, 18 px blur, 14% white border | Toasts and labels on bright photos |

Rules:

- Glass needs something to blur. The page background carries a soft leaf, sun and sky gradient for that, and hero and room photos do the rest.
- Never put glass on glass. One layer per area.
- Keep tables, calendars, forms, stat blocks and price breakdowns solid white.
- Text on glass must keep 4.5:1 contrast. Raise opacity before lowering text contrast.
- Every glass class falls back to a solid, near-opaque surface when `backdrop-filter` is unsupported or the user prefers reduced transparency.

## Components

- `.btn` with `btn-primary`, `btn-dark`, `btn-ghost`, `btn-danger`, `btn-sm`. Minimum 44 px tall (36 px for admin `btn-sm`).
- `.field` inputs with a visible 3 px focus ring and `aria-invalid` styling.
- `AvailabilityCalendar`: price per night in every cell, bold on Friday and Saturday, striped when booked, ink for start and end, `leaf-tint` for the range.
- `StatusChip` maps each booking status to one tone. Don't invent new status colors.

## Motion

Short transitions only (150 ms to 500 ms for photo zoom). The one exception is the payment and cancellation timeline, which plays once on scroll-in: the line draws, dots pop and text rises over about 1.5 s with an exponential ease-out. All motion is disabled under `prefers-reduced-motion`.

## Photos

Real photographs only. See `docs/photo-credits.md`. Served as WebP in card (640 px) and full (1600 px) sizes with width, height and alt text, generated by `npm run photos`.
